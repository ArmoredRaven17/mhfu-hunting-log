How this works

  • Pick a quest on the left — search by quest name, monster or locale, or browse by board and star: the Village Elder, Nekoht, the Guild Hall (up to G3★) and the Training School.
  • The quest fills in its own locale and objective; everything else is yours to write.
  • Urgent and Key pills mark the quests that move a star on. Where a quest has its own unlock or special conditions, they show under its details.
  • Save Entry adds it to the logbook on the right. Click any entry to edit it again.
  • Timestamp is on by default, so the date is set the moment you save. Turn it off to fill the date in yourself.
  • Farming the same quest? Turn on Farming and the form stays filled after each save, so back-to-back runs only need whatever actually differed.
  • Already saved a run and want another like it? Open it, change what differed, and press Save as New to file it as a second hunt instead of overwriting the first.
  • Tick entries and press Copy Selected to put them on the clipboard — handy for pasting a session into Discord. Shift-click a second tick box to take everything in between; All ticks the whole log.

Saving

  • The log saves itself in this browser as you type — including the entry you're part-way through writing, which is waiting for you when you come back.
  • New starts an empty logbook — save the current one first if you want to keep it.
  • Save writes it out to a .json file and Open loads one back. Keep separate files for separate playthroughs.
  • Clearing your browser's site data wipes the in-browser copy, so keep a file if the log matters.

MHFU Hunting Log

An unofficial, non-commercial logbook for Monster Hunter Freedom Unite — record what you hunted, what you wore, who came along, and why. Not affiliated with, endorsed by, or supported by Capcom.

The quest list — every quest's name, star, locale, objective, monsters, time limit, fee and reward — and the monster, item and weapon icons come from the same author's MHFU LookUp, whose fee, reward, time limit and description fields were checked against the game's own quest files. Downloadable Event Quests and the Treasure quests aren't in that list, so they aren't here either.

The quest data comes from the Monster Hunter community wikis — Monster Hunter Wiki (Fandom), monsterhunterwiki.org and the MHP2G @wiki — and is shared under CC BY-SA 4.0.

Monster Hunter Freedom Unite and all of its names, data and icons are © CAPCOM CO., LTD. The UI textures and the MHFU font are shared with the same author's MHGU fan apps, and the app itself is a port of the MH3U Hunting Log and the MHGU Hunting Log.
